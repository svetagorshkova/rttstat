# Архив игрока РТТ

Статическая страница (без сервера и сборки): `index.html` + `data.js`.
Всё считается в браузере: процент побед, личные встречи, результаты по категориям, график рейтинга.

## Как выложить на GitHub Pages

1. Создайте репозиторий (например, `rtt-archive`) и загрузите файлы `index.html`, `data.js` и `README.md`.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту страница появится по адресу `https://<ваш-логин>.github.io/rtt-archive/`.

Про приватность: GitHub Pages публичны, и у страницы стоит `noindex` (поисковики её не должны индексировать), но по ссылке её увидит любой. В данных есть имена детей-соперников. Если хотите закрытый доступ, откройте `index.html` локально (двойной клик) или храните репозиторий приватным без Pages.

## Как пополнять (всё в `data.js`)

**Самый простой способ:** внизу страницы есть блок «Добавить матч». Выберите вкладку (одиночный, парный, рейтинг), заполните поля, нажмите «Сформировать» и «Скопировать», затем вставьте результат в `data.js` в место, которое подскажет страница. Форма ничего не сохраняет сама и работает прямо в браузере.

Если хотите править руками, формат такой. Даты везде в формате `ДД.ММ.ГГГГ`.

### 1. Новый одиночный матч

Найдите нужный турнир в `singles` и добавьте строку в его `matches`:

```js
["Фамилия Имя Отчество", 12345, "W", "6-3,6-2", 500, 14, "Москва", "20.10.2026"],
//  соперник            id РТТ  W/L   счёт      очки соп. возраст город   дата
```

`id` соперника можно взять из ссылки на его страницу на RTTStat, а если его нет, поставьте `null`.

Если турнира ещё нет, добавьте блок целиком (в начало списка):

```js
{ id: 306000, name: "Название турнира", city: "Москва", group: "до 15 лет", cat: "III А", matches: [
  [ ... ],
]},
```

### 2. Новый парный матч

Добавьте объект в `doubles` по образцу соседних:

```js
{ tour: { id: 306000, name: "Название турнира", city: "Москва", group: "до 15 лет", cat: "III А" },
  partner: "Фамилия Имя", partnerId: 111, partnerPts: 300,
  opp1: "Соперник 1", opp1Id: 222, opp2: "Соперник 2", opp2Id: 333,
  res: "W", score: "6-3,6-4", pts1: 400, pts2: 250, date: "20.10.2026" },
```

### 3. Рейтинг по месяцам

В `ratingHistory` в нужный год добавьте `[место, очки]` в конец массива `vals`.
Для нового года добавьте блок `{ year: 2027, group: "до 15 лет", startMonth: 1, vals: [[место, очки]] }`.

### 4. Сводка вверху

В `player` обновите `updated`, `age`, `singles` / `doubles` (очки, места, число турниров).

### 5. Турниры

- `toursYearSingles` / `toursYearDoubles` — турниры за последний год (колонки описаны в комментарии в файле; «признак зачёта» 0 означает, что турнир не зачтён).
- `history` — полная история одиночных турниров.

## Проверка после правок

Откройте `index.html` в браузере. Если таблицы пустые, значит, в `data.js` синтаксическая ошибка (чаще всего забытая запятая или кавычка). Подробности видны в консоли браузера (F12).

## Откуда данные

Со страницы https://rttstat.ru/player/47927 по состоянию на 08.10.2026 (рейтинг, турниры, история рейтинга). Матчи с 27.10.2025 по 05.10.2026 (57 одиночных и 22 парных) перенесены из публичной части страницы и со скриншотов PRO-версии, расширенная статистика (RS-уровень, форма, процент побед над младшими и старшими и т. д.) тоже со скриншотов.

Итоги сверены с источником: одиночные 34 победы из 57 (60%), парные 12 из 22 (55%).

Матчи после 05.10.2026 и свежие рейтинг и очки нужно добавлять вручную (удобнее всего через форму внизу страницы). Новые турниры, которые ещё не попали в рейтинг, можно держать в списке `pending` в `data.js`, пока источник их не учтёт.
